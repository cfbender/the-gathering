# Mana symbols

These 84 SVGs and `symbols.json` were downloaded from Scryfall's
[`/symbology`](https://api.scryfall.com/symbology) API on 2026-09-20. They are bundled with the
frontend so mana symbols work without runtime requests to Scryfall.

Scryfall provides the files for use in Magic: The Gathering community software. Magic: The
Gathering, mana symbols, and the symbol artwork are copyright Wizards of the Coast. This project is
not produced by or endorsed by Wizards of the Coast or Scryfall.
